# Шумер · личное учебное приложение

Открытая статическая оболочка для личного изучения истории Месопотамии: лекции, карта, хронология, карточки повторения и заметки.

В этом репозитории находятся только программный код, оформление, значки и конфигурация установки. Здесь нет личных ссылок, видеозаписей, исходных презентаций, конспектов курса, ключей или зашифрованных пакетов материалов.

Пользователь подключает личный JSON со своего устройства. Приложение обрабатывает и сохраняет его локально; содержимое файла не отправляется на сайт. Официальный онлайн-плеер загружается только по нажатию кнопки. Добавленные пользователем видео сохраняются в IndexedDB для просмотра без сети.

На iPhone/iPad сначала добавьте сайт на экран «Домой», затем откройте его с новой иконки и импортируйте личный курс. Очистка данных сайта удаляет локальные заметки и файлы.
